# Full Stack Open 2026 - University of Helsinki 

This repository contains my solutions to the exercises of **Full Stack Open** course by the University of Helsinki. 

Through this intensive, hands-on program, I mastered modern JavaScript-based web development, building production-ready applications from scratch and focusing on deep architectural understanding.

## 🛠️ Tech Stack & Skills Developed
* **Frontend:** React, Redux Toolkit, React Router, Custom Hooks, Context API
* **Backend:** Node.js, Express
* **Database:** MongoDB & Mongoose (ODM)
* **Testing:** Jest, Cypress (E2E Testing)
* **Tooling & Best Practices:** Vite, ESLint, REST APIs, Token-based Authentication (JWT)

---

## 📂 Repository Structure & Modules Completed

* **Part 0: Fundamentals of Web Apps** – HTTP requests, AJAX, and traditional vs. Single Page Apps (SPA) architecture.
* **Part 1: Introduction to React** – Component state, event handling, and JavaScript array methods.
* **Part 2: Communicating with Server** – Fetching data with Axios, rendering collections, and basic CSS styling (The Phonebook app).
* **Part 3: Programming a Server with NodeJS and Express** – Building REST APIs, deploying to production (Render/Fly.io), and connecting to MongoDB.
* **Part 4: Testing Express Servers, User Administration** – Backend structure, Mongoose schemas, token authentication (JWT), and unit/integration testing with Jest.
* **Part 5: Testing React Apps** – Frontend login systems, local storage, prop types, and component testing.
* **Part 6: Advanced State Management** – Managing complex app-wide state using **Redux**, Redux Toolkit, and asynchronous actions.
* **Part 7: React Router, Custom Hooks, Styling** – Client-side routing, building reusable custom hooks, and styling apps with UI frameworks.

---

## 🎯 Key Takeaways & Engineering Mindset
* **Single Source of Truth:** Mastered React's unidirectional data flow and how to manage state correctly to avoid re-rendering bugs.
* **Defensive Programming:** Implemented robust backend validation, error-handling middleware, and async/await wrappers.
* **Testing as a Habit:** Learned to write reliable tests (backend integration and frontend component tests) before shipping to production.
